🔧 Factor Común
Guía N°15 · Extrae el elemento común de todos los términos

¿Qué es el Factor Común?

Es un elemento (número o letra) que está presente en todos los términos de una expresión algebraica.

ab ± ac = a(b ± c)
1

Identifica el número o letra que aparece en TODOS los términos.

2

Extrae el factor común y escríbelo fuera del paréntesis.

3

Dentro del paréntesis escribe lo que queda de cada término al dividir por el factor.

4

Verifica distribuyendo: el resultado debe ser la expresión original.

⬜ Diferencia de Cuadrados
Guía N°15 · Factorización inversa a (a+b)(a-b)

La fórmula clave

Si tienes una resta de dos cuadrados perfectos, puedes factorizar así:

x² − y² = (x + y)(x − y)
Ejemplo: x² − 64 = (x)² − (8)² = (x + 8)(x − 8)
1

Identifica las raíces cuadradas de ambos términos.

2

Escribe dos factores: uno con suma y otro con diferencia: (√a + √b)(√a − √b)

3

Verifica multiplicando usando (a+b)(a-b) = a² - b²

⚠️ Recuerda
Debe ser una resta (no suma) y ambos términos son cuadrados perfectos.
Cuadrados perfectos: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169…

💎 Trinomio Cuadrado Perfecto
Proceso inverso del Binomio al cuadrado

La fórmula

El 1er y 3er término deben ser cuadrados perfectos. El 2do término debe ser el DOBLE del producto de las raíces del 1er y 3er término.

x² + 2·x·y + y² = (x + y)²
x² − 2·x·y + y² = (x − y)²
🔍 Checklist para reconocerlo
✓

¿El 1er término es un cuadrado perfecto? → x², a², 4x², 25y²...

✓

¿El 3er término es un cuadrado perfecto? → 9, 16, 25, 49...

✓

¿El 2do término = 2 × (√1er) × (√3er)? → Verifica el coeficiente.

📋 Trinomio Ordenado
Factorización como producto de dos binomios con un término común

La fórmula

Es el proceso inverso de multiplicar dos binomios con término común.

x² + bx + c = (x + p)(x + q)
p + q = b
(suman el coef. de x)
p · q = c
(multiplican el término independiente)
1

Busca dos números p y q que sumen b y multipliquen c.

2

Escribe el resultado como (x + p)(x + q).

3

Si el coeficiente de x² no es 1, busca primero el factor común.

Ejercicio 1
x² + 8x + 12 = ?
p+q=8 · p·q=12
p=2, q=6 (2+6=8 ✓, 2×6=12 ✓)
= (x + 2)(x + 6)

Ecuación Lineal con 2 incógnitas

Tiene la forma ax + by = c donde a, b, c son números racionales (a≠0, b≠0).

y = −a/b·x + c/b

Tiene infinitas soluciones: cualquier par (x, y) que satisfaga la ecuación.

Sistema de Ecuaciones

Dos ecuaciones con las mismas incógnitas. Se busca el par (x, y) que satisface ambas simultáneamente.

3x + 8y = 75
−x + 4y = 35
Método de Igualación — 4 pasos
1
Despeja la misma incógnita en ambas ecuaciones
2
Iguala las expresiones obtenidas
3
Resuelve para la incógnita restante
4
Reemplaza y verifica la solución

Ejemplo resuelto paso a paso

Sistema: 6x + 2y = 0 y −3x + 2y = 9
1

Despeja y:
Ec.1: 2y = −6x → y = −3x
Ec.2: 2y = 9 + 3x → y = (9 + 3x)/2

2

Iguala: −3x = (9 + 3x)/2

3

Resuelve: −6x = 9 + 3x → −9x = 9 → x = −1

4

Reemplaza: y = −3(−1) = 3
∴ (x, y) = (−1, 3)

Sistema a
2x + 5y = 26
x + 2y = 11
De Ec.2: x = 11 - 2y
Reemplaza: 2(11-2y)+5y=26
22-4y+5y=26 → y=4
x=11-8=3
→ (x,y) = (3, 4)
👆 Clic para ver
Sistema b
5x − 2y = −4
3x + 4y = −18
De Ec.1: 2y=5x+4 → y=(5x+4)/2
Reemplaza en Ec.2: 3x+4·(5x+4)/2=-18
3x+2(5x+4)=-18 → 13x=-26 → x=-2
y=(5(-2)+4)/2=-3
→ (x,y) = (−2, −3)
👆 Clic para ver
Sistema c
2x + 3y = −14
x − 6y = −60
De Ec.2: x = 6y - 60
Reemplaza: 2(6y-60)+3y=-14
12y-120+3y=-14 → 15y=106 → y=7.07
→ (x,y) ≈ (−17.6, 7.07)
